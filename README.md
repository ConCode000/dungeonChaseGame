# dungeonChaseGame
Dungeon Chase Game is a simple 2D game where the player navigates through a dungeon filled with enemies and traps. The goal is to survive and reach the treasure while avoiding or fighting dungeon monsters.

Language: Java 17
Build System: Gradle 8.5

This project was developed as part of the Programming II course taught by Prof. Dr. Christopher Auer during the summer semester of 2024.

Some initial code and the project structure (including graphics) were provided as part of the exercise. Building on this foundation, most of the functionalities were independently implemented according a exercise description.
